FAQ

Is my data sent to the cloud?

Only when you have added your own Claude API key and click an AI action — then a short summary (no images, no personal identifiers) is sent directly to api.anthropic.com. Nothing goes through a CartIQ server; CartIQ doesn't have one.

Do I need admin permissions to install it?

No. It's a normal Chrome extension — "Load unpacked" in Developer mode for this pre-release version, no system-level install.

Does it work without an API key?

Duplicate detection works without one. The AI summary, cheaper-alternatives search, and seller-trust check need a personal key from console.anthropic.com.

Is this an official AliExpress tool?

No — CartIQ is an independent, unofficial extension, not affiliated with AliExpress or Alibaba Group.

🔐 Privacy first

Current version: v0.3.2 (CartIQ-v0.3.2.zip). CartIQ is not in the Chrome Web Store, so you install it manually: download the ZIP, extract it to a folder you will keep, open chrome://extensions, turn on Developer mode and click "Load unpacked". Chrome will not update it by itself.

האם המידע שלי נשלח לענן?

רק אם הוספתם מפתח Claude API אישי ולחצתם על פעולת AI — אז סיכום קצר (בלי תמונות, בלי מזהים אישיים) נשלח ישירות ל-api.anthropic.com. שום דבר לא עובר דרך שרת של CartIQ — אין לו כזה.
